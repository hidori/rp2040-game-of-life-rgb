# Game of Life RGB for RP2040

RP2040 とカラー LED マトリクスを使用したカラー版ライフゲームです。

## ディレクトリ構成

```text
.
├── .claude/                       # Claude Code の設定
├── .github/                       # GitHub の設定
├── .gitignore                     # git の除外設定
├── AGENTS.md                      # コーディングエージェント向けの指示
├── CLAUDE.md                      # Claude Code 向けの指示
├── LICENSE                        # ライセンス条文
├── Makefile                       # 作業用のタスク定義
├── README.md                      # プロジェクトの主旨と概要
├── SPEC.md                        # プロジェクトターゲットの仕様書
├── TODO.md                        # プロジェクトの課題管理
├── arduino-cli.yaml               # arduino-cli の設定
├── rp2040-game-of-life-rgb.ino    # スケッチ本体
├── mise.toml                      # mise の設定
└── renovate.json                  # Renovate の設定
```
